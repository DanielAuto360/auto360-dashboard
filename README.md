# Auto360 — Dashboard Supervisión Comercial

Dashboard en tiempo real para supervisión de ejecutivos comerciales Auto360.

## Stack
- React 18
- Google Sheets API v4
- Deploy: Vercel

## Setup local
```bash
npm install
npm start
```

## Deploy
1. Push a GitHub
2. Conectar repo en vercel.com
3. Deploy automático

## Configuración
En `src/App.jsx` líneas 6-7:
- `SHEET_ID`: ID del Google Sheets
- `API_KEY`: Google Sheets API Key
